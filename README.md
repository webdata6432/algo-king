# Algo King — private personal workspace

From the project directory run `python3 server.py` (Python 3.10+). Open http://127.0.0.1:8765 on that computer. Demo backtests, CSV imports, return charts and saved comparisons work without accounts. Browser storage is specific to the browser profile and origin. Keep original CSVs.

## Historical data
The bundled Sensex daily dataset covers 23 observed sessions, 21 Oct–20 Nov 2026. Its source is https://www.investing.com/indices/sensex-historical-data . Demo stock prices and demo minute candles are generated separately. Coverage of a preset window depends on available observations.

Import one CSV per instrument from Market Returns or Backtester. Daily format: symbol,date,open,close. Minute format: symbol,date,time,open,high,low,close. Times are IST, HH:MM, candle start. The optional symbol column must match the instrument entered. For example files generated by Download example CSV, use a source name such as Demo fixture. For options select Option contract, enter expiry/strike/CE or PE in the symbol, and supply its own minute premiums and applicable historical lot size.

For personal Upstox historical retrieval, set UPSTOX_ACCESS_TOKEN in your shell privately. Use the provider's instrument master to identify the exact instrument. Example:

    python3 history.py 'NSE_EQ|INE002A01018' RELIANCE 2026-10-01 2026-10-31 reliance-minute.csv

Add --daily for daily data. Import the output into the app. Coverage, expired derivatives and entitlements depend on the endpoint and personal account. Missing historical option candles require a separate authorized export for that specific contract. See https://upstox.com/developer/api-documentation/v3/get-historical-candle-data/ .

## Private connections
For Angel One, install requirements.txt with pip in a private virtual environment. Set ANGEL_API_KEY and ANGEL_ACCESS_TOKEN in the server environment; restart the server. Test connection requests an NSE market-data quote using the SmartAPI SDK. Only the local Python process reads secrets. Avoid putting credentials in CSV files, HTML or source.

Live Market Depth uses the independent Upstox full-market-quote endpoint. Set UPSTOX_ACCESS_TOKEN on the local server, restart it, and search by exact NSE equity symbol. The book displays provider-supplied positive-price levels up to 30 per side and the provider timestamp. Refresh using Get latest snapshot. Public preview mode cannot connect to a personal server running elsewhere. See https://upstox.com/developer/api-documentation/get-full-market-quote/ .

## Execution and comparison
Execution rules are documented inside Backtester. Reported return is net P&L divided by total entry value. Drawdown is peak-to-trough closed-trade net equity. Calendar groups use the session date; weeks start on Monday. Comparison requires matching dataset identity, dates, fees and slippage. Entry rules and position sizing can vary between strategies.


The Supabase schema is included for future setup. The repository runs locally without deployment or sync jobs.
